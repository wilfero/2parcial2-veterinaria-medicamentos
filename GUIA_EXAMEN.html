Segunda serie: Agregar (POST) y Editar (PUT) 5 puntos

Checklist de requisitos

  • La función almacenada Agregar sigue la nomenclatura establecida: Usp_Tbl_Medicamentos_Agregar
  • Recibe como parámetros los atributos de la tabla (11 parámetros p_*, sin la PK porque es SERIAL)
  • Maneja los errores con un bloque de excepción de PostgreSQL: EXCEPTION WHEN OTHERS THEN ... SQLERRM
  • Devuelve mensajes para operaciones exitosas (exito 1) y para errores (exito -1)
  • La función almacenada Editar sigue la nomenclatura: Usp_Tbl_Medicamentos_Editar
  • Recibe la llave primaria (p_CodigoMedicamento) y los datos que se actualizan
  • Maneja errores con EXCEPTION y devuelve mensajes de éxito, de registro inexistente (exito 0) y de error
  • API Agregar con método POST: consume la función Agregar, recibe un objeto JSON y responde en JSON
  • API Editar con método PUT: consume la función Editar; la PK va en la URL y los datos en el body; responde en JSON
  • Valida los datos obligatorios recibidos por las API (DTO con class-validator + ValidationPipe)
  • Se implementaron y probaron ambas en Postman, y se verificó en PostgreSQL

1. Función almacenada Agregar (database/02_StoredProcedures.sql)

CREATE OR REPLACE FUNCTION Usp_Tbl_Medicamentos_Agregar(
    p_NombreMedicamento VARCHAR(150), p_Laboratorio VARCHAR(100), p_Presentacion VARCHAR(100),
    p_Concentracion VARCHAR(50), p_ViaAdministracion VARCHAR(50), p_Existencia INT,
    p_PrecioCompra DECIMAL(12,2), p_PrecioVenta DECIMAL(12,2), p_FechaVencimiento DATE,
    p_RequiereReceta SMALLINT, p_Estado SMALLINT
)
RETURNS TABLE ("exito" INT, "mensaje" VARCHAR(250), "codigoMedicamento" INT) AS $$
DECLARE
    v_Codigo INT;
BEGIN
    INSERT INTO Tbl_Medicamentos (...) VALUES (...)
    RETURNING CodigoMedicamento INTO v_Codigo;

    RETURN QUERY SELECT 1, 'Medicamento agregado correctamente.'::VARCHAR(250), v_Codigo;
EXCEPTION
    WHEN OTHERS THEN
        RETURN QUERY SELECT -1, ('Error al agregar el medicamento: ' || SQLERRM)::VARCHAR(250), NULL::INT;
END;
$$ LANGUAGE plpgsql;

2. Función almacenada Editar

CREATE OR REPLACE FUNCTION Usp_Tbl_Medicamentos_Editar(
    p_CodigoMedicamento INT,  -- llave primaria
    p_NombreMedicamento VARCHAR(150), ... , p_Estado SMALLINT
)
RETURNS TABLE ("exito" INT, "mensaje" VARCHAR(250)) AS $$
BEGIN
    IF NOT EXISTS (SELECT 1 FROM Tbl_Medicamentos WHERE CodigoMedicamento = p_CodigoMedicamento) THEN
        RETURN QUERY SELECT 0, ('No existe el medicamento con codigo ' || p_CodigoMedicamento || '.')::VARCHAR(250);
        RETURN;
    END IF;

    UPDATE Tbl_Medicamentos SET NombreMedicamento = p_NombreMedicamento, ...
    WHERE CodigoMedicamento = p_CodigoMedicamento;

    RETURN QUERY SELECT 1, 'Medicamento editado correctamente.'::VARCHAR(250);
EXCEPTION
    WHEN OTHERS THEN
        RETURN QUERY SELECT -1, ('Error al editar el medicamento: ' || SQLERRM)::VARCHAR(250);
END;
$$ LANGUAGE plpgsql;

5. Controlador: API POST y API PUT (src/medicamentos/medicamentos.controller.ts)

// POST /api/medicamentosAgregar  -> recibe un objeto JSON en el body
@Post('medicamentosAgregar')
async agregar(@Body() dto: MedicamentoDto) {
  const resultado = await this.medicamentosService.agregar(dto);   // Usp_Tbl_Medicamentos_Agregar
  return this.responder(resultado, { codigoMedicamento: resultado.codigoMedicamento });
}

// PUT /api/medicamentosEditar/:codigo  -> PK en la URL + datos en el body
@Put('medicamentosEditar/:codigo')
async editar(@Param('codigo', codigoPipe) codigo: number, @Body() dto: MedicamentoDto) {
  const resultado = await this.medicamentosService.editar(codigo, dto); // Usp_Tbl_Medicamentos_Editar
  return this.responder(resultado, { codigoMedicamento: codigo });
}

En el servicio: pool.query('SELECT * FROM Usp_Tbl_Medicamentos_Agregar($1, ..., $11)', [...]). Con responder(), un exito 1 se devuelve como 200/201, un 0 como 404 y un -1 como 400.

1. Función almacenada Buscar

CREATE OR REPLACE FUNCTION Usp_Tbl_Medicamentos_Buscar(p_CodigoMedicamento INT)
RETURNS TABLE ("codigoMedicamento" INT, "nombreMedicamento" VARCHAR(150), ... , "estado" SMALLINT) AS $$
BEGIN
    RETURN QUERY
    SELECT m.CodigoMedicamento, m.NombreMedicamento, ... , m.Estado
    FROM Tbl_Medicamentos m
    WHERE m.CodigoMedicamento = p_CodigoMedicamento;
EXCEPTION
    WHEN OTHERS THEN
        RAISE EXCEPTION 'Error al buscar el medicamento: %', SQLERRM;
END;
$$ LANGUAGE plpgsql;

2. Función almacenada Eliminar

CREATE OR REPLACE FUNCTION Usp_Tbl_Medicamentos_Eliminar(p_CodigoMedicamento INT)
RETURNS TABLE ("exito" INT, "mensaje" VARCHAR(250)) AS $$
BEGIN
    IF NOT EXISTS (SELECT 1 FROM Tbl_Medicamentos WHERE CodigoMedicamento = p_CodigoMedicamento) THEN
        RETURN QUERY SELECT 0, ('No existe el medicamento con codigo ' || p_CodigoMedicamento || '.')::VARCHAR(250);
        RETURN;
    END IF;

    DELETE FROM Tbl_Medicamentos WHERE CodigoMedicamento = p_CodigoMedicamento;

    RETURN QUERY SELECT 1, 'Medicamento eliminado correctamente.'::VARCHAR(250);
EXCEPTION
    WHEN OTHERS THEN
        RETURN QUERY SELECT -1, ('Error al eliminar el medicamento: ' || SQLERRM)::VARCHAR(250);
END;
$$ LANGUAGE plpgsql;

4. Controlador: API GET y API DELETE

// GET /api/medicamentosBuscar/:codigo
@Get('medicamentosBuscar/:codigo')
async buscar(@Param('codigo', codigoPipe) codigo: number) {
  const datos = await this.medicamentosService.buscar(codigo);   // Usp_Tbl_Medicamentos_Buscar
  if (!datos) throw new HttpException({ exito: 0, mensaje: `No existe el medicamento con codigo ${codigo}.`, datos: null }, 404);
  return { exito: 1, mensaje: 'Medicamento encontrado.', datos };
}

// DELETE /api/medicamentosEliminar/:codigo
@Delete('medicamentosEliminar/:codigo')
async eliminar(@Param('codigo', codigoPipe) codigo: number) {
  const resultado = await this.medicamentosService.eliminar(codigo); // Usp_Tbl_Medicamentos_Eliminar
  return this.responder(resultado, { codigoMedicamento: codigo });
}

codigoPipe (un ParseIntPipe) valida que la PK sea un número entero. Si no lo es, responde 400.

5. Postman paso a paso: GET (Buscar)

  1. Nueva petición con el método GET. Sin body.
  2. URL: http://localhost:3000/api/medicamentosBuscar/1 y luego Send. Debe responder 200: {"exito":1,"mensaje":"Medicamento encontrado.","datos":{"codigoMedicamento":1,...}}
  3. Código inexistente: /medicamentosBuscar/999 responde 404: "No existe el medicamento con codigo 999."
  4. Código inválido: /medicamentosBuscar/abc responde 400: "El codigo del medicamento debe ser un numero entero."

6. Postman paso a paso: DELETE (Eliminar)

  1. Nueva petición con el método DELETE. Sin body.
  2. URL: http://localhost:3000/api/medicamentosEliminar/6 y luego Send. Debe responder 200: {"exito":1,"mensaje":"Medicamento eliminado correctamente.","datos":{"codigoMedicamento":6}}
  3. Envíalo otra vez: responde 404, "No existe el medicamento con codigo 6."
  4. Confirma con GET /medicamentosBuscar/6, que responde 404. En pgAdmin: SELECT * FROM Tbl_Medicamentos WHERE CodigoMedicamento = 6; devuelve 0 filas.
